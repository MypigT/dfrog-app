## 今日进展

### 1. 统一聊天调度（核心）
`/chat` 入口现在对一条消息做**意图分类**后分流到四个子系统
（`backend/main.py` 的 `_classify_sync` / `_resolve_root_reply` 等）：

| 意图 | 去向 | 说明 |
|---|---|---|
| 闲聊 | DeepSeek LLM 流式回复 | `stream_naiwa_reply`，SSE 逐字推给桌面端 |
| 自然语言提醒 | `/reminders` | 如"十分钟后提醒我喝水"→定时任务 + 到期 SSE 推送 |
| 自然语言速记 | `/notes` | 如"记住：明天下午两点去面试"→入库，支持 `/notes/summarize` |
| 派活（Agent 任务） | `/agent` → `agent.py: run_agent` | 调 Claude CLI 干活；无目录时先反问，答路径后写 `agent_root.txt` 开工 |

### 2. Agent 目录机制
- `backend/data/agent_root.txt` 持久化 Agent 工作根目录
- 无目录派活 → 回复索要路径 → 用户提供路径 → 存根 → 开工
- 测试脚本 `worklog/chat_dispatch_test.py` 用 `.bak` 临时挪走根目录文件来验证这条链路，测完自动还原

### 3. 其它已有能力（回归用）
- 看屏幕：`/vision`、`/screenshot`，视觉走 qwen3.8-max（DashScope）；聊天命中"看见/屏幕/干嘛"等关键词自动带截图走多模态
- 主动互动：`/events`（SSE 事件广播，桌宠主动说话/做动作）
- 状态与动作：`POST /status`、`POST /action`（眨眼、跟随鼠标等）
- 打包：`启动奶龙.exe`（PyInstaller，frozen 时数据写到 `%APPDATA%\dfrog`）
